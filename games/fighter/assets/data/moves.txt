# Frame data. One line per move; every length is in frames at 60 per second,
# distances in millimetres, speeds in millimetres per frame. tools/framedata.mjs
# prints the table from this file and checks it; the game reads the same file.
#
#   move * <slot> k=v ...      the default for every fighter declared after it
#   fighter <id> k=v ...       a fighter: name hp walk back jump jumpfx grav dash dashback (jump: the hop, up tapped twice)
#                              and the specials sp1 sp2 sp3 super: numpad motion then its button,
#                              P punch, K kick, X either (236P = down, down-forward, forward + punch; [4]6 = charge)
#   move <id> <slot> k=v ...   changes one move of that fighter
#
# Slots: the direction held with the button. 5P 8P 2P 6P = punch (mid, up: high, down: low, forward: a stepping
# variant), 5K 8K 2K 6K = kick (the same), JP JK = in a hop, THROW = punch + kick together, SP1-3, SUPER.
# Levels: a high is blocked standing (BLOCK) and passes over a crouch (down + BLOCK, or a low attack); a low must be
# blocked low; a mid is blocked either way.
# Move keys: name (underscores are spaces)  su ac rc (startup, active, recovery)  dmg  lv (h m l: how it must be blocked)
#   hs bs (hitstun, blockstun)  hstop (hitstop)  pushh pushb (pushback speed on hit / block)
#   kd (knockdown)  launch (upward speed, sends the target airborne)  mg (meter gain)
#   hits rehit (several hits, frames between)  inv (invulnerable frames from the start)
#   mv mvfrom mvto (forward speed on those frames)  hit=x0,y0,x1,y1  ext=x0,y0,x1,y1 (limb hurtbox)
#   proj=speed,life,size  gdmg (guard gauge filled when blocked, default twice dmg)  flags: air crouch throw special super
