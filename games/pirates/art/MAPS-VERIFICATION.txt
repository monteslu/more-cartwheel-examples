Palm Lagoon map, 2026-10-31

Second original map generated with Blender tools/make-coast.py -- --lagoon.
New coastline polygons, terrain height table, baked color atlas and GLB.
Large sheltered western bay, central peninsula and southern island form
different routes from the volcanic map. Harbor locations differ. Terrain,
collision, navigation and wave shelter use the selected map's outlines.
Title T / controller SELECT cycles maps. Verified controller SELECT changes
pirates.map to 1, and START launches the selected map in the playable cart.

Romdev four-bot race on Lagoon, 3600 frames: bank=[11,12,13,9], goods=51.
All four captains reached resources and returned to harbor. Zero skipped
renders. Repeated switches 1,0,1,0,1 produced stable node counts for each
map (1554/1463 before adding the single CargoGroup node); no growing scene
node count observed. This does not establish absence of all memory leaks.

NPC spawns now snap to the selected map's navigation grid. Cargo grouped
under one refraction exclusion because the engine has a 16-node exclusion
limit. However switching maps still produces excessive foam around cargo;
the screenshot out/pirates-lagoon-romdev.png exposes this unresolved defect.
