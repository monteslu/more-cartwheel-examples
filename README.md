# more-cartwheel-examples

Games built on [cartwheel-engine](https://github.com/monteslu/cartwheel-engine)
to push the engine: each game is written to find what the engine lacks, and
the generic fixes go back into the engine. Shared screen or split screen,
one pad per player.

Each game has its own folder under `games/` and builds like the ones in
cartwheel-examples (`scripts/fetch-deps.sh`, `scripts/build.sh`).
